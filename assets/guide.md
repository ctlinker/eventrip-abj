your event convoy ticketing platform:
1. Brand Identity & Color Palette

    Primary Colors: Clean white background base with vibrant pure green accents.
    Typography: Satoshi font for a modern, tech-forward aesthetic.
    Tailwind CSS Inspiration: Subtle diagonal hatched patterns ("bandes hachurées"), incorporated both into background accents (like floating spheres) and UI section dividers.

2. Core Service & Value Proposition

    Event Ticketing Focus: Clean event reservation platform focused on selling access to events (festivals, concerts, shows) along with organized transport/convoys, rather than raw bus seat booking.
    No Clutter: Excludes unnecessary visual elements like prominent QR codes or complex seat selection maps.

3. Event Card Structure & UI Elements

    Floating Category Badges: Pill-style category tags positioned cleanly floating above/outside the top-left corner of each card (rather than overlaid directly on top of the image).
    Departure & Seat Ratio Chips: Horizontal arrangement below the event image displaying multiple departure points enclosed in subtle, eye-catching rectangular chips (e.g., [Departure Point] [Reserved / Capacity]).

4. Hero Landing Page & Motion Asset

    Integrated Cartoon Bus Asset: A 2D flat vector cartoon bus/shuttle that is compact in length.
    Event Vibe via Graffiti: Features static event-themed graffiti and graphic stickers on its body to give it an event feel without dynamic music notes or flashing lights.
    Seamless Loop: Designed to fit within a compact hero section space on the landing page, running on a smooth, continuous, non-distracting loop.
